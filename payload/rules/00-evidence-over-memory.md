# Evidence over memory

A factual claim in this project needs a source retrieved in this session.

This applies to: library and framework versions, API shapes and limits, pricing,
regulations, competitor claims, market figures, and anything with a date in it.
Model memory has a training cutoff and this project ships to a live audience.

When you cannot verify something, write `Unverified:` in front of it and say
where you looked. That sentence is worth more to the team than a fluent guess.

Firecrawl is installed for exactly this. Use `firecrawl_developer_search` for
code questions, `firecrawl_search` for the open web, `firecrawl_scrape` for a
known page, `firecrawl_parse` for the team's own documents, and
`firecrawl_find_tools` plus an `alexandria` execution when a number has to be real.
