# Examples

Worked artefacts you can copy. These are filled-in examples, not blank templates:
the point is to show the standard, including the parts teams usually leave vague.

| File | Use it for |
| --- | --- |
| `good-prompt-vs-bad-prompt.md` | Writing a task prompt Bob can finish unsupervised |
| `adr-template.md` | Recording a decision that passed the three ADR gates |
| `spec-example.md` | A spec with acceptance criteria a test can assert |
| `eval-case-example.md` | One eval case, its grader, and its recorded result |
| `wizard-template.sh` | The fixed library half of a `$wizard` script |
| `firecrawl-queries.md` | Tool choices for twelve real research questions |
