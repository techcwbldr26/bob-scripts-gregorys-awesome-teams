# SNAP Data Tables

The [SNAP](https://www.fna.usda.gov/snap/supplemental-nutrition-assistance-program) page provides access to information on all aspects of the program. See the SNAP page on [Applicants and Recipients](https://www.fna.usda.gov/snap/applicant-participant) for detailed information about eligibility requirements and benefits. SNAP is the federal name for the program. State programs may have different names.
